# Ces Fashion

E-commerce premium de moda feminina construído com Next.js, React, TypeScript,
TailwindCSS e Framer Motion.

## Stack

- Next.js App Router
- React + TypeScript
- TailwindCSS
- Framer Motion
- Lucide React
- Arquitetura preparada para login, carrinho, checkout, pagamentos e painel administrativo

## Como rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Scripts

```bash
npm run dev
npm run build
npm run typecheck
npm run lint
```

## Estrutura

```txt
src/
  app/                  Rotas do App Router
  components/
    layout/             Header e Footer
    sections/           Hero, produtos, marca e destaques
    ui/                 Componentes reutilizáveis
  data/                 Catálogo mockado
  lib/                  Utilitários
  types/                Tipos compartilhados
```
